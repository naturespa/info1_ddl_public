# 情報I Digital & Data Lab

情報Iのデジタル分野・データ活用分野を、実験と確認問題で学ぶ公開用教材サイトです。
単元構成は **岡田メソッドExcelシート**（兵庫県立明石南高等学校 岡田）の章立てに1対1で対応しています。

## 規模

| 項目 | 数 |
|---|---|
| 単元 | 18（デジタル10 + データ活用8） |
| 実験 | 120（各単元 5〜8） |
| 確認問題 | 144（各単元8） |
| 重要語句 | 216 |

すべての実験は**数値や文字を自分で入力して結果が変わる**形式です。読むだけの実験はありません。

## 実験に使っている実データ

Excelシートの演習データをそのまま初期値として使っています。

- 身長20人分（四分位数・度数分布）
- パンの重量10個（Z検定：母平均60.272g、母標準偏差0.8188g）
- 卵1パックの価格15店舗（t検定：母平均117円）
- 学科・実技の得点10人分（対応のあるt検定）
- 男女×カレーの喫食回数（カイ二乗検定：χ²=13.1907、p=0.000281）
- 1980〜2018年の平均気温39年分（移動平均・トレンド）

## 確認問題

各単元8問。難易度をラベルで表示しています。

- **基礎** — 教科書レベル
- **共通テスト** — 大学入学共通テスト「情報I」相当
- **ITパスポート** — IPA ITパスポート試験の過去問（出典表示あり）
- **基本情報** — IPA 基本情報技術者試験の過去問（出典表示あり）

過去問題の著作権はIPA（情報処理推進機構）に帰属します。出典は各問題に明記しています。

## 公開版の方針

- 生徒氏名や名簿データは含めません。
- 入力する識別子は半角数字4桁だけです。
- 学習結果は利用中のブラウザの `localStorage` に保存します（キー: `joho-ddl-public-v2:` + 4桁番号）。
- 成績画面から `4桁番号_ddl_YYYYMMDD.json` を出力できます。
- JSONファイルを回収し、ExcelやPower Queryで集計する運用を想定しています。

### JSONの構造（v2）

```json
{
  "version": 2,
  "exportedAt": "2026-08-18T09:00:00.000Z",
  "studentCode": "1205",
  "drafts":      { "base": [1, 2, 1, 0, 1, 1, 1, 2] },
  "submissions": { "base": { "answers": [...], "correct": 7, "submittedAt": "..." } },
  "experiments": { "base-0": true, "base-1": true },
  "summary": {
    "totalScore": 82,
    "perspective": { "knowledge": 85, "thinking": 80 },
    "quizCorrect": 122, "quizMax": 144,
    "experimentDone": 96, "experimentMax": 120,
    "completedLessons": 12, "lessonCount": 18
  }
}
```

v1（旧版）のJSONとは互換性がありません。`experiments` のキーが `base-1`〜`base-3`（1始まり）から
`base-0`〜`base-7`（0始まり）へ変わり、`perspective` が追加されています。

## ファイル構成

```
app/
  page.tsx                 画面全体（学習マップ・単元・成績・JSON出力）
  layout.tsx               ルートレイアウト
  globals.css              全スタイル
  lib/
    types.ts               型定義
    calc.ts                計算ライブラリ（基数変換・補数・浮動小数点・統計・検定）
    ui.tsx                 実験の共通部品（入力欄・結果表示・グラフ）
    lessons.ts             単元データの統合
    lessons-digital.ts     デジタル分野10単元
    lessons-data.ts        データ活用分野8単元
  experiments/
    index.tsx              単元IDから実験を呼び分ける
    digital.tsx            デジタル分野の実験67個
    data.tsx               データ活用分野の実験53個
```

計算はすべて `lib/calc.ts` に集約しています。統計関数（正規分布・t分布・カイ二乗分布）は
SciPyと小数点以下8桁まで一致することを確認済みです。
