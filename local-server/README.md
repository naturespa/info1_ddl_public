# 1年次 DDL 提出・成績管理（2026-11-24更新）

学校PCで受信したDDLの提出JSONを管理する、オフライン対応の管理サイトです。Node.jsの標準機能だけで動きます。Excel出力にも外部サービスや追加インストールは必要ありません。

## 既存の管理サイトを更新する

1. 起動中のサーバーの黒い画面で **Ctrl+C** を押して終了します。
2. 更新ZIPを、現在のサーバーとは**別のフォルダー**にすべて展開します。
3. 展開先の **update.bat** を実行し、現在の `server.cjs` があるフォルダーを指定します。例：`C:\1nen\ddl1` または `C:\ddl1-json`。
4. 以前と同じフォルダーの **start.bat** で起動し、[http://localhost:3003/admin](http://localhost:3003/admin) を開き直します。ブラウザーに古い画面が残る場合は Ctrl+F5 を押します。

更新プログラムは、起動中の3003番サーバーを検出したら処理を止めます。更新対象は下記の**プログラム6ファイルのみ**です。更新前のプログラムは設置先の `.ddl-admin-backups` に控えを残します。`data`、名簿、既存の `start.bat`、環境変数の設定には触れません。

- `server.cjs`
- `admin.html`
- `reports.cjs`
- `report-catalog.cjs`
- `xlsx.cjs`
- `admin-state.cjs`

Windowsの設定で更新プログラムを実行できない場合は、サーバー停止後、**この6ファイルをすべて**現在のフォルダーにコピーして上書きしてください。2ファイルだけの差し替えでは起動できません。`data`フォルダーは移動・削除せず、元の場所に残します。

新規設置の場合は6ファイルと `start.bat` を同じフォルダーへ配置してください。Node.jsが必要です。ポートは従来どおり3003番です。

## 画面の使い方

| 画面 | 内容 |
|---|---|
| 提出一覧 | 従来の総合点・分野別点・受信日時・再提出回数・元JSONの保存。名簿照合と既存のCSV出力も維持 |
| 観点別成績 | デジタル・データ活用の通常学習と分野別テストについて、3観点を並べて表示 |
| アンケート | 成績と分けて回答を表示。設問グループの切替、全回答の詳細表示 |
| ごみ箱 | 削除した提出を表示し、1件ずつ・まとめて復元 |

クラス、番号・名前の検索、名簿照合、最新だけ／全提出を選べます。番号順に並びます。「最新だけ」は修正後の番号ごとに受信日時が最新の提出を表示します。過去の提出から不足項目を自動補完せず、1つの提出JSONに含まれる結果をそのまま扱います。

「テスト対象」は本試験・追試・本試験と追試のうち最新・教員用・デモを選べます。本試験が初期選択です。テストとアンケートの両方に適用します。選んだ種類のアンケートが1つの提出内に複数あれば、回答日時が最新のものを表示します。

## 観点別成績とExcel

| 項目 | 知識・技能 | 思考・判断・表現 | 主体性 |
|---|---:|---:|---:|
| デジタル通常学習 | /100 | /100 | /100 |
| データ活用通常学習 | /100 | /100 | /100 |
| デジタル分野別テスト | 通常 /30 | 通常 /70 | 採点対象外 |
| データ活用分野別テスト | 通常 /30 | 通常 /70 | 採点対象外 |

通常学習の総合点は知識60%＋思考40%で、主体性は別評価です。テストはJSONの `byViewpoint.points` と `maxPoints` を使用するため、正解数や得点率を点数と混同しません。満点が異なる記録も保存されている満点で表示します。旧版等で観点別内訳がない場合は「—／内訳なし」、未受験は「—／未受験」と表示し、0点とは区別します。サーバーで問題の再採点は行いません。

**観点別成績 Excel（表示分）** は、クラス・検索・照合・最新／全提出の条件に一致する提出を出力します。全体を出す場合はクラスを「すべて」にして検索・照合条件を解除します。

Excelには次のシートが入ります。

- 観点別成績：1提出1行。4区分×3観点、名簿照合、試験種類・満点・終了日時・保存ファイル
- テスト履歴：対象の提出に含まれる全試験（教員用・デモも含む）。成績表の選択対象とは分けて確認
- クラス集計：得点のある件数と平均。未受験・内訳なしを0点にせず除外
- 配点と出力条件：換算方法、選択条件、空欄の意味

**従来の提出一覧CSV・分野別テストCSVは、従来の列を維持し、有効な全提出を出力します。** クラス等の画面上の絞り込みは反映しません。ごみ箱の提出は除外し、管理画面で修正した番号・名前は反映します。

## アンケートとExcel

現在の公開教材にある24問（バージョン2）の回答を読み取ります。Q11〜Q16は「学ぶ前」「現在」を別列にし、複数選択、単元名、自由記述も含めます。Excelには「アンケート回答」「アンケート集計」「設問と選択肢」「出力条件」の4シートを出力します。クラス・全体の切替方法は成績Excelと同じです。画面の設問グループを絞っても、Excelには全設問を出力します。

未回答者も回答状態付きで一覧に残します。「判断できない」「機会がなかった」（元データの0）は文字で表示し、平均から除外します。学ぶ前と現在の差は両方に1〜5を回答した同一回答者だけを対象にします。「学ぶ前」は現在から振り返って回答した自己評価で、実測の事前テストではありません。アンケートを成績へ加点しません。

未対応の旧形式が含まれる場合は、消さずに原文JSONの列へ出力します。回答が元の提出JSONに含まれていなければ復元はできません。生徒端末に回答が残っている場合は、テストを受け直すのではなく、JSONの再送信で管理側に反映できます。

## 名前・出席番号の修正

各行の **名前・番号修正** で番号（半角4桁）と名前（姓と名をスペースで区切る）を編集します。「この提出だけ」「同じ番号の提出すべて」を選べます。ごみ箱の提出は一括修正に含みません。

修正先の番号に既存の提出がある場合もファイルを統合・上書きしません。「最新だけ」では同じ番号の最新1件になるので、「全提出」で履歴を確認してください。修正先の番号が存在すると編集画面に案内を表示します。

修正情報は `data/admin-state.json` に保存し、一覧・名簿照合・Excel・CSVに反映します。生徒端末の内容と受信時の元JSONは変更しません。「元JSONを保存」は受信時の名前・番号のままです。変更前の管理情報は `data/.admin-history` に保存します。バックアップではこれらも含めて **dataフォルダーごと**保存してください。

## 不要な提出の削除・復元

行の「削除」、またはチェックボックスと「選択した提出を削除」でごみ箱へ移動します。確認画面に対象の番号・名前・受信日時を表示します。完全削除は行わず、元JSONはそのまま残します。ごみ箱画面から復元できます。最新提出を削除すると、以前の提出が「最新だけ」の対象になる場合があります。

## 名簿と接続

名簿は従来どおり `C:\1nen\ddl1\meibo.scv` を優先し、なければ同じ場所の `meibo.csv` を読みます。A列は4桁番号、B列は名前。見出しの有無、UTF-8・Shift_JIS・UTF-16LEに対応します。全角・半角スペースを無視して名前を照合します。重複番号は別途表示します。変更する場合は既存の `ROSTER_FILE` をそのまま利用できます。

管理画面・Excel・修正・削除APIは先生PCのlocalhostだけで操作できます。生徒の送信先と受信APIは従来どおりです。接続確認は `http://localhost:3003/health`。受信記録の保存先は `DATA_DIR` の設定があればそれを使い、なければ `server.cjs` と同じ場所の `data` です。
