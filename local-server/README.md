# 1年次 DDL JSON提出管理（学校PC用）

公開サイトの「JSON送信」から送られた学習記録を、学校PCに保存して確認するための受信サーバーです。Node.js の標準機能だけで動き、インターネットにつながっていなくても管理画面を開けます。2年次用のサーバーとは別のフォルダー・ポートを使います。

## 初回の準備（Windows）

1. [Node.js の LTS 版](https://nodejs.org/)を学校PCにインストールします。コマンドプロンプトで `node --version` が表示されることを確認してください。
2. `C:\ddl1-json` フォルダーを作り、このフォルダー内の `server.cjs`、`admin.html`、`start.bat` をそこへコピーします。`node_modules` や教材サイトの全ファイルは不要です。
3. `C:\ddl1-json\start.bat` をダブルクリックします。終了するまでコマンドプロンプトは閉じないでください。
4. **学校PC上で** `http://localhost:3003/admin` を開きます。`admin.html` を直接開いた場合もこのURLに移動します。管理画面には学校PCのLAN IPアドレスが表示されます。
5. 生徒には表示された **IPv4アドレスの数字だけ** を伝えます。生徒は [1年次 DDL 公開サイト](https://naturespa.github.io/info1_ddl_public/)のトップで4桁番号と名前を入力し、「JSON保存」の下の「JSON送信」にその数字を入れて送信します。名前は「山田 太郎」のように姓と名の間をスペース1文字で区切ります。`http://` や `:3003` は入力しません。

提出完了画面の受付番号と、管理画面の提出一覧を照合できます。送信された元JSONは `C:\ddl1-json\data` に1提出1ファイルで保存されます。再送しても前のファイルは上書きされません。管理画面から4桁番号・名前・総合点（200点満点）・分野別点・再提出・分野別テストを確認し、名前入りの一覧CSV・テストCSV・元JSONをダウンロードできます。名簿照合やサーバー側での再採点はしません。更新前に提出された名前のないJSONは「未登録」と表示されるため、必要なら新しい画面から再提出してもらってください。

## すでに1年次用サーバーを設置している場合

起動中のコマンドプロンプトで `Ctrl+C` を押して終了し、新しい `server.cjs` と `admin.html` を `C:\ddl1-json` に上書きしてください。`data` フォルダーはそのまま残し、`start.bat` で再起動します。以前のJSONと名前入りの新しいJSONを同じ管理画面で確認できます。2年次用サーバーには変更は必要ありません。

## 接続できないとき

- 学校PCで `http://localhost:3003/health` を開き、`"ok":true` を確認します。管理画面のIPが「取得中」のままなら、`http://localhost:3003/admin` から開き直し、起動したコマンドプロンプトのエラーを確認してください。
- 生徒PCで `http://<学校PCのIP>:3003/health` にアクセスして確認します。接続できない場合は、同じ学校ネットワークか、学校PCのWindowsファイアウォールで TCP 3003 番の受信が許可されているかを確認します。ネットワーク側で端末間通信が制限される場合は管理者に相談してください。
- 2年次用（3002番）と同時に起動できます。生徒には、1年次用管理画面に表示されたIPを伝えてください。
- 学校PCのIPが変わった場合は、新しいIPを伝えます。管理画面の「更新」で表示も更新できます。
- `data` フォルダーのバックアップを取ってください。名簿や提出内容を含むJSONを学校の規定に沿って扱ってください。

ポートが競合する場合は、別のアプリを確認して3003番を空けてください。教材サイトの送信先ポートは3003番で固定です。
