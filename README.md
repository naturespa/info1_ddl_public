# 情報I Digital & Data Lab

情報Iのデジタル分野・データ活用分野を、実験と確認問題で学ぶ公開用教材サイトです。

## 公開版の方針

- 生徒氏名や名簿データは含めません。
- 入力する識別子は半角数字4桁だけです。
- 学習結果は利用中のブラウザの `localStorage` に保存します。
- 成績画面から `4桁番号_ddl_YYYYMMDD.json` を出力できます。
- JSONファイルを回収し、ExcelやPower Queryで集計する運用を想定しています。
