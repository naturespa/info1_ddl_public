# 情報I Digital & Data Lab

情報Iのデジタル分野・データ活用分野を、実験と確認問題で学ぶ公開用教材サイトです。
単元構成は **岡田メソッドExcelシート**（兵庫県立明石南高等学校 岡田）の章立てに1対1で対応しています。

## 規模

| 項目 | 数 |
|---|---|
| 単元 | 19（デジタル11 + データ活用8） |
| 実験 | 129（各単元 5〜9） |
| 確認問題 | 153（D0のみ9問、他は各単元8問） |
| 重要語句 | 233 |

すべての実験は**数値や文字を自分で入力して結果が変わる**形式です。読むだけの実験はありません。

## 教科書との対応

第4章「情報のデジタル化」（p.44〜75）と第5章「コンピュータのしくみ」（p.80〜91）を読み合わせ、
用語・定義・例題・単位の規約をそろえています。

- データ量の計算は、教科書の表1に合わせて **1KB＝1,024B** で行います。
  IPAの問題で「1MB＝1,000kB」と指定される場合に備え、各実験でSI表記も折りたたみで併記しています。
- 教科書の例題を、そのまま実験の初期値にしています（56−17の補数、1.6GHz÷4周期、
  AAAABBBBBAAAのランレングス、ハフマン符号化の74.2%など）。
- 基数を表す添え字（例: 2進数(2) / 10進数(10) / 16進数(16)）は教科書の表記に合わせています。

## 実験に使っている実データ

Excelシートの演習データをそのまま初期値として使っています。

- 身長20人分（四分位数・度数分布）
- パンの重量10個（Z検定：母平均60.272g、母標準偏差0.8188g）
- 卵1パックの価格15店舗（t検定：母平均117円）
- 学科・実技の得点10人分（対応のあるt検定）
- 男女×カレーの喫食回数（カイ二乗検定：χ²=13.1907、p=0.000281）
- 1980〜2018年の平均気温39年分（移動平均・トレンド）

## 確認問題

各単元8問（D0のみ9問）。難易度をラベルで表示しています。

- **基礎** — 教科書レベル
- **共通テスト** — 大学入学共通テスト「情報I」相当
- **ITパスポート** — IPA ITパスポート試験の過去問（出典表示あり）
- **基本情報** — IPA 基本情報技術者試験の過去問（出典表示あり）

過去問題の著作権はIPA（情報処理推進機構）に帰属します。出典は各問題に明記しています。

## 観点別評価への対応

学習結果を、学習指導要領の観点に対応させて集計します。

| 観点 | 集計対象 | 重み |
|---|---|---|
| 知識・技能 | 確認問題153問の正答率 | 60% |
| 思考・判断・表現 | 実験129個の実施率 | 40% |

主体性は自動採点しません。ダッシュボードの弱点分析と、実験の実施状況を教員が見て評価してください
（Excelの `sss` シートと同じ運用です）。JSONに自由記述欄は含めていません。

## 理解度ダッシュボード

成績ページに、送信済みの確認問題から弱点を割り出すダッシュボードがあります。

- **講評** — 全体の正答率、基礎と応用の差、実験の実施状況から、事実だけを根拠にした短い所見を出します。
- **難易度別の到達度** — 基礎／共通テスト／ITパスポート／基本情報の4段階で正答率を比べます。
  差が20ポイント以上あると「用語は覚えたが使えていない」といった偏りが見えます。
- **単元別の理解度マップ** — 全単元を 定着（80%以上）／あと一歩（60%以上）／要復習（60%未満）／未受験 で色分けします。
  色だけに頼らず、必ず文字ラベルと数値を併記しています。押すとその単元へ移動します。
- **いま優先して立て直したい単元** — 正答率の低い順に最大3単元。単元ごとに「つまずいている可能性」
  「間違えた問題で問われていたこと」「こうすれば分かるようになります（実験番号つきの手順3つ）」を表示します。
- **間違えた問題の復習リスト** — 自分の答え・正解・解説を並べた一覧を、折りたたみで表示します。

学び直しの手順は、単元データの `remedy` に単元ごとに書いてあります（`lessons-digital.ts` / `lessons-data.ts`）。
文言を変えたい場合はそこを直してください。

状態の色は、色覚多様性を考慮した検証（CVD分離 ΔE 11.2 / 通常視 22.1）を通しています。

## 公開版の方針

- 生徒氏名や名簿データは含めません。
- 入力する識別子は半角数字4桁だけです。
- 学習結果は利用中のブラウザの `localStorage` に保存します（キー: `joho-ddl-public-v2:` + 4桁番号）。
- 成績画面から `4桁番号_ddl_YYYYMMDD.json` を出力できます。
- JSONファイルを回収し、ExcelやPower Queryで集計する運用を想定しています。

### JSONの構造（v2）

```json
{
  "version": 2,
  "exportedAt": "2026-08-18T09:00:00.000Z",
  "studentCode": "1205",
  "drafts":      { "base": [1, 2, 1, 0, 1, 1, 1, 2] },
  "submissions": { "base": { "answers": [...], "correct": 7, "submittedAt": "..." } },
  "experiments": { "base-0": true, "base-1": true },
  "summary": {
    "totalScore": 83,
    "perspective": { "knowledge": 85, "thinking": 80 },
    "quizCorrect": 130, "quizMax": 153,
    "experimentDone": 100, "experimentMax": 129,
    "completedLessons": 12, "lessonCount": 18
  }
}
```

v1（旧版）のJSONとは互換性がありません。`experiments` のキーが `base-1`〜`base-3`（1始まり）から
`base-0`〜`base-7`（0始まり）へ変わり、`perspective` が追加されています。

## ファイル構成

```
app/
  page.tsx                 画面全体（学習マップ・単元・成績・JSON出力）
  layout.tsx               ルートレイアウト
  globals.css              全スタイル
  lib/
    types.ts               型定義
    calc.ts                計算ライブラリ（基数変換・補数・浮動小数点・統計・検定）
    ui.tsx                 実験の共通部品（入力欄・結果表示・グラフ）
    lessons.ts             単元データの統合
    lessons-digital.ts     デジタル分野10単元
    lessons-data.ts        データ活用分野8単元
  experiments/
    index.tsx              単元IDから実験を呼び分ける
    digital.tsx            デジタル分野の実験76個
    data.tsx               データ活用分野の実験53個
```

計算はすべて `lib/calc.ts` に集約しています。統計関数（正規分布・t分布・カイ二乗分布）は
SciPyと小数点以下8桁まで一致することを確認済みです。
