# データ活用95問版の実装と公開前の確認事項

2026年11月16日

## 現在の状態

95問用の採点・40分の時間設定・問95の次に表示する14項目のアンケートを実装した。
**95問の本番問題データは未作成であり、この変更だけでは95問版は有効にならない。**
既存の暗号化問題ファイルは変更していない。新しいファイルがなければ既存65問版を読み込む。
この変更は公開前の準備として扱い、問題データの準備と実機確認までドラフトのままにする。

## 新版の仕様

| 項目 | 設定 |
|---|---|
| 問題数 | 95問 |
| 知識・技能 | 38問・40点 |
| 思考・判断・表現 | 57問・60点 |
| 満点 | 100点 |
| 制限時間 | アンケートを含め40分 |
| 得点の計算 | 知識正解数÷38×40 ＋ 思考正解数÷57×60 |
| 丸め | 換算点は小数第3位まで。正解数も保存 |
| アンケート | 問95の「次へ」で14項目を1ページに表示。採点対象外 |

デジタル65問との合計は**160問**になる。アンケートはこの160問に含めない。

## 問題データの配置

以下の新規ファイルだけが新版になる。既存のファイルを上書きしない。

- 本試験：`public/exams/data-c1-main-95-v1.json` ～ `data-c7-main-95-v1.json`
- 教員用：`public/exams/data-teacher-95-v1.json`
- 追試を作る場合：`public/exams/data-makeup-4桁番号-95-v1.json`

各JSONのsetIdは拡張子を除いたファイル名と一致させ、areaを「データ活用」とする。
暗号形式は既存のAES-GCM／PBKDF2形式と同じ。復号後の問題数・観点の個数・問題IDの一意性・4択・正答位置を検証してから開く。
問題数を表示だけ95に変えたり、同一問題を複製して95問に見せたりはしない。

## 既存の記録の保持

新版はsetId末尾の `-95-v1` で識別する。旧65問と保存キーを分け、既存の途中経過や成績を上書きしない。
95問の結果を旧形式100問と誤判定して読み飛ばさないよう、新版だけを例外として受け入れる。
デジタルの問題・配点・時間・既存の結果更新ルール、通常学習の得点・Gは変更しない。

## アンケート

Q1～Q6は「学ぶ前を振り返って」と「現在」の自己評価。実際に学習前に行った調査とは区別する。

1. 平均値と中央値の使い分け
2. ばらつきを使う集団の比較
3. 相関と因果の区別
4. 整理・分析方法の選択
5. シミュレーションの条件・試行回数
6. AI等の分析結果の検算
7. 数字やグラフで考えることへの興味
8. 今後の探究・生活での活用意向
9. 確かめ直した頻度
10. 自分に合った学習速度
11. 役立った仕組み（最大3つ）
12. 困った点と改善希望
13. 理解・考え方の具体的な変化
14. データで調べたい疑問

項目は任意とし、未回答・判断できないを得点化しない。
解答一覧から先に提出しようとした場合も、一度アンケートページを表示する。
時間切れ時は未表示／表示済みと入力途中の回答を区別して保存する。
回答は途中保存と提出結果の `dataSurvey` に入り、JSONの `examDetails` に含まれる。
現行の受信サーバーはそのJSONをそのまま保存するため、サーバーの更新は不要。
アンケート集計専用CSVの追加はこの変更には含めない。
